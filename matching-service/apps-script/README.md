# つながりラウンジ β版（Google Apps Script）

プロフィール登録・検索の試作品です。**このGitHub上のファイルを置いただけでは、サービスは動きません。Google Apps Scriptに2ファイルをコピーしてデプロイする必要があります。**

## 実装している機能
- ニックネーム、対象区分、年代、目的、短い自己紹介の登録
- 公開承認されたプロフィールの検索
- 登録直後は「審査中」とし、管理者がスプレッドシートで公開状態を「公開」に変えたものだけ一覧表示
- 登録者が登録IDと削除キーで自分のプロフィールを削除
- メールアドレス、電話番号、住所、写真は収集しない
- メッセージ送信機能なし

## デプロイ手順
1. https://script.google.com/ を開き、Googleアカウントで新しいプロジェクトを作成。
2. 最初からある `コード.gs` の中身を削除し、このフォルダの `Code.gs` の内容を貼り付ける。
3. 左の「＋」→「HTML」を選び、ファイル名を `Index` にして、このフォルダの `Index.html` の内容を貼り付ける。
4. 保存する。
5. 関数一覧から `setup` を選び「実行」。アクセス許可を確認して許可する。作成されたスプレッドシートURLは、Apps Scriptの「実行ログ」で確認できる。シートの公開状態列は、運営者だけが編集する。
6. 「デプロイ」→「新しいデプロイ」→種類「ウェブアプリ」。
7. 実行ユーザーは自分、アクセスできるユーザーは公開テストに必要な設定を選ぶ。組織アカウントでは「全員」が選べない場合がある。
8. デプロイして発行されたWebアプリURLを開き、登録・検索をテストする。

## プロフィールを公開する手順
- `setup` を実行すると「つながりラウンジ_プロフィール管理」スプレッドシートが作成される。
- 登録されたプロフィールは初期状態「審査中」。
- 運営者が内容を確認し、公開してよい場合だけ「公開状態」列を「公開」に変更する。
- 非公開にする場合は「審査中」など「公開」以外の値に戻す。
